# Farbenlehre

Yazi flavor generated by `yazi-flavor-from-nvim` from the Omarchy theme Neovim is using.

- Flavor name: `farbenlehre`
- Neovim colorscheme: `aether`
- Palette: neovim.lua colors, with colors.toml filling the gaps
- Preview: aether highlight colors, with vscode-theme.json filling other scopes

Re-run `yazi-flavor-from-nvim` after changing themes. This directory is replaced when the theme name matches.
